# 운율 시주 시각 기준 (KST / LMT / 진태양시)

상태: 문서 (계산식 변경 없음)  
관련 코드: `src/lib/saju/calendar/localMeanTime.ts`, `src/lib/saju/pillars/build.ts`

---

## 1. 세 기준 구분

| 이름 | 정의 | 운율 v1 지원 |
|------|------|----------------|
| **KST 벽시계** | 입력한 `Asia/Seoul` 시각 그대로 | ✅ 기본 (`birthPlace` 없음) |
| **LMT (지방시)** | 벽시계 + 경도 보정<br>`offsetMin = (lonEast − 135°) × 4` | ✅ 선택 (`birthPlace` 해석 가능 시, **시주만**) |
| **진태양시 (true solar)** | LMT + **균시차(EOT)** | ❌ 미구현 |

혼동 금지:

- **LMT ≠ 진태양시**
- 현재 코드의 `hourCalcClock`은 LMT(또는 미적용 시 벽시계)이다.
- `solarTerms.ts`의 “진태양 황경”은 **절기 천문 계산**용이며, 시주 LMT와 무관하다.

적용 범위:

- **연·월·일**: 항상 KST 벽시계 시민일 (`SolarInstant`)
- **시주**: `hourPillar(dayStem, hourCalcClock.hour)` — 2시간 구간 공식(`hourBranchIndex`)은 불변

---

## 2. 시주 2시간 구간 (불변)

`hourBranchIndex(hour) = floor(((hour + 1) % 24) / 2)`

| 시지 | 시계 **시(hour)** (분 무시) |
|------|------------------------------|
| 子 | 23, 0 |
| 丑 | 1, 2 |
| … | … |
| 酉 | 17, 18 |
| 戌 | 19, 20 |
| 亥 | 21, 22 |

분이 바뀌어도 **같은 hour**면 시지는 같다. LMT는 hour에 들어가기 **전** 시계만 옮긴다.

---

## 3. 세 방식이 달라지는 때

서울 seed 경도 `126.978°E` → offset ≈ **−32.088분** → 구현은 `Math.round` → **−32분**.

### 3.1 酉 → 戌 (17–18 vs 19–20)

| KST 벽시계 | KST 시지 | Seoul LMT 시계 | LMT 시지 |
|------------|----------|----------------|----------|
| 18:59 | 酉 | 18:27 | 酉 |
| **19:00** | **戌** | **18:28** | **酉** ← 분기 |
| 19:31 | 戌 | 18:59 | 酉 |
| **19:32** | 戌 | **19:00** | **戌** ← LMT도 戌 |
| 19:17 (1981 기준) | 戌 | 18:45 | **酉** |

→ **KST 19:00–19:31** 구간에서만 KST=戌 / Seoul LMT=酉로 갈라진다.  
진태양시(EOT)는 날짜마다 ±십수 분이라, 이 경계 전후에서 LMT와 **또** 갈라질 수 있으나 **미구현**.

### 3.2 亥 → 子 / 子 → 丑 (자정 근처)

| 경계 | KST만 바뀌는 시각 | Seoul LMT와 갈라지는 벽시계 창 |
|------|-------------------|-------------------------------|
| 亥→子 | 23:00 | **23:00–23:31** (KST=子, LMT=亥) |
| 子→丑 | 01:00 | **01:00–01:31** (KST=丑, LMT=子) |

子시 자체(23–0시) 안에서는 KST/LMT가 같은 시지를 유지하는 구간이 넓다.  
자정 **시민일**은 연월일 기둥에만 쓰이고, LMT가 23시로 wrap되어도 **일주는 바꾸지 않는다** (현 정책).

### 3.3 날짜가 바뀌는 LMT wrap

예: KST `00:10` + Seoul −32분 → LMT `23:38`.

- 시주: LMT hour=23 → 子 (KST hour=0도 子 → **시지 동일**인 경우 많음)
- 일주: **KST 시민일 유지** (전날로 되돌리지 않음)

시지가 갈리는 wrap 예는 子→丑 창(위 표)을 쓴다.

### 3.4 진태양시가 추가로 갈라지는 때 (미구현 안내)

EOT는 연중 대략 −14 ~ +16분대.  
LMT 경계 직전/직후(±32분 창과 겹칠 때)에 **LMT ≠ 진태양시**가 될 수 있다.  
운율 v1은 이 층을 넣지 않으므로, “만세력 앱 진태양시”와 1:1 대조 시 경계 케이스는 별도 검증이 필요하다.

## 5. 최종 시주 기준으로의 적합 여부 (판정 메모)

- **내부 일관성**: LMT는 경도만의 결정적 보정; 날짜 하드코딩 없음; 연월일 분리 유지 → 구조적으로 적합.
- **외부 만세력 대조**: 경도 LMT를 쓰는 자료와는 경계 창에서 정합 가능. **균시차까지 쓰는 진태양시 만세력**과는 경계 전후 불일치 가능 → “진태양시 최종 기준”이라고 **부르면 안 됨**.
- **권장 표기**: 운율 v1 시주 = **「출생지 경도 반영 지방시(LMT), 균시차 미반영」**.
