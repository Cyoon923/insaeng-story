## data-quality issues

판정 불일치와 **분리** 기록. 전문가 답변은 수정하지 않음.

### DQ-1 (확정) — Case 02 / E3: 일간 오독

- **제시 원국:** 癸卯 甲子 **甲子** 庚午 → 일간 **甲**
- **E3 raw:** 「일간: 庚」, 요약표도 「02 | 庚 | … | 강한 신약」
- **근거:** 시주 천간 庚을 일간으로 읽은 것으로 보임. 득령·득지를 庚의 子=死로 채점, 甲을 편재로 처리.
- **영향:** E3의 Case 02 「신약」은 **다른 명식(庚일간)**에 대한 판정. E1·E2·E4와의 신강 vs 신약 대비를 **해석적 disagreement로 쓰지 말 것.**

### DQ-2 (확정) — Case 03 / E3: 월지 오독

- **제시 원국:** 癸亥 **乙丑** 丙寅 甲午 → 월지 **丑**
- **E3 raw:** 「득령: 월지 寅 → 丙의 寅 = 長生」, 「寅월 초봄」, 요약 「寅=生」; 동시에 합충에서 丑午를 언급해 지지 목록은 혼재.
- **영향:** 득령 +1이 제시 월지(丑)가 아닌 일지(寅) 기준으로 잡힘. 최종 「신강」 방향은 E1·E2·E4와 겹치나, **점수·득령 근거는 오염.**

### DQ-3 (경미) — Case 02 / E1: 차트 일지 표기

- E1 차트에 일주를 `甲`/`甲`으로 표기(일지가 甲으로 보임).
- 본문 근거는 「월지와 일지에 子수」로 **子일지·甲일간**을 올바르게 사용 → 표기 오류, 판정 축은 유효.

### DQ-4 (경미) — Case 05 / E1: 차트 년지 표기

- E1 차트 년지를 `甲`으로 표기(제시는 庚子 → 年支 子).
- 본문에 「년지 子수」 언급 → 표기 오류, 판정 축은 대체로 유효.

### DQ-5 (메모, 오독 아님) — E3의 만세력 의문

- Case 01·04·08에서 날짜↔원국 재검증 권고를 적었으나, 명시적으로 **사용자 제시 원국을 적용**한다고 함.
- 일간 치환은 Case 02만 해당. 만세력 메모 자체는 DQ가 아니라 전문가 조건부 메모.
