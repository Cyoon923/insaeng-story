## 1. 비겁 → 일간 강화 방향

| Expert | 원문 요지 |
|---|---|
| E1 | 비견·겁재는 일간과 동일 오행으로 세력 직접 확장; 건록·양인에 록 형성 시 가장 강력히 신강 유도. 표: 강화(신강)/방조. |
| E2 | 비견·겁재 기본 방향 **강화(+)**. 비겁 = 동기·조력. 존재만으로 동일 크기 플러스는 아님. |
| E3 | 비겁 = 동류·일반 조력(비견=자아 강화). 다만 過多 시 劫財/比肩 누설 위험; 상황 의존 양면(A-9). 표: 強(+조력), 개인가중 +0.5/+0.3. |
| E4 | 비겁은 세력을 그대로 더하는 가장 직접적 조력원. 지지 비겁(통근)이 천간 비겁보다 실질 가중치 큼. 생조 그룹(+)에 포함. |

**항목 상태:** 4/4 기본 방향 = 강화(+). E3만 過多·양면 예외를 방법론에서 명시.

## 2. 인성 → 일간 강화 방향

| Expert | 원문 요지 |
|---|---|
| E1 | 정인·편인 = 생조로 보완·지탱 → 강화. 무근+인성 과다 시 효율 저하(모자멸자 등); 체감은 통근 비겁보다 약할 수 있음. |
| E2 | 편인·정인 = **생조(+)**. 인성 묶음 가능. 비겁과 같은 작용은 아님(동기여 vs 생 전달). |
| E3 | 인성 = 조력(扶). 기본 조력이나 **印重身弱 / 財破印 / 印綬 太多** 시 약화. 印 3~4 + 식상 0 = 의심. 개인가중 +0.4/+0.5, 印重 감점. |
| E4 | 인성 = 생으로 에너지 유입 → 신강(+). 무근+인성 과다 시 ‘생다갈/부유’; 통근형 비겁과 질감 다름. |

**항목 상태:** 4/4 기본 = 강화/조력. 과다·무근 예외는 E1·E3·E4가 명시. E2는 작용 구분만(방향 뒤집기 아님).

## 3. 식상 → 일간 약화 방향

| Expert | 원문 요지 |
|---|---|
| E1 | 식신·상관 = 설기 → 신약. 식신 완만, 상관 급격·과도. |
| E2 | 식신·상관 = **설기(−)**. 1차 방향 같음. 강한 일간+약한 식신 하나 ≠ 즉시 약화. |
| E3 | 식상 = 설기 → 약화(1차). 단 **식상 得氣**(식상생재·식신제살 등)면 체→용, 세력 단일 약화로만 처리하면 격 놓침. 개인가중 −0.4/−0.6. |
| E4 | 식상 = 설기 → 신약(−). 식신 완만, 상관 급격; 천간 다수 투출 시 설기태과. |

**항목 상태:** 4/4 1차 = 약화/설기. E3만 격·유통 시 예외를 방법론 본문에 강하게 둠.

## 4. 재성 → 일간 약화 방향과 작용 기제

| Expert | 방향 | 작용 기제 (원문) |
|---|---|---|
| E1 | 약화 | 일간이 극·다스림 + **재극인**으로 지원군 차단 → 소모·약화. 표: 극루/재극인. |
| E2 | 소모(−) | 일간이 재를 극해야 하므로 힘 사용. **식상=설기 / 재성=소모** 구분. |
| E3 | 소모(耗) | 일간이 極하는 오행; 식상보다 약하지만 재 다수 시 빼앗김 반복(財多身弱). |
| E4 | 신약(−) | 통제·관리 과정의 **소모(분산)**. 편재=광역, 정재=좁고 집요. 탈기군. |

**항목 상태:** 4/4 방향 = 약화. 기제 표현은 소모/극루·재극인/통제비용으로 **부분 합의**, 세부 결은 다름.

## 5. 관성 → 일간 약화 방향

| Expert | 원문 요지 |
|---|---|
| E1 | 정관·편관 = 극벌 + 비겁 제압 → 세력 **가장 강하게** 억제·신약화. |
| E2 | 편관·정관 = **극제(−)**. 관성 약·일간 강하면 한 글자만으로 신약화 판단 금물. |
| E3 | 1차 일간 약화는 동일(극제). 정관=격 안정, 편관=격 붕괴 risk; **격 형성은 별도**. “관=일간 약” 단정 금지. |
| E4 | 직접 극 → 탈기군 중 **최강 강도**. 편관 강압, 정관 규율적 압박. |

**항목 상태:** 4/4 1차 세력 방향 = 약화/극제. E3는 격 층위 분리 강조.

## 6. 비겁+인성 묶음 허용 여부

| Expert | 원문 |
|---|---|
| E1 | 허용(자세력군) — 정량 강약에 유효. 단 비겁=근육/자주력, 인성=외부 지원; 통근 비겁 > 단순 인성 생조. |
| E2 | 최상위 방향: 생조측 = 비겁+인성 가능. 실제 계산은 메커니즘 분리(동기 vs 생조). |
| E3 | 1차 시험용으로 **인성·비겁 = 조력 1묶음** 유효. 印重·劫財 등 별도 감점으로 균열 감지. |
| E4 | 생조 그룹(비겁+인성) vs 탈기 — 1차 개수 비교 허용, 2차 자리 질 보정. |

**항목 상태:** 4/4 **방향 묶음 허용**. 전원 “같은 작용/같은 강도”는 아님.

## 7. 식상+재성+관성 묶음 허용 여부

| Expert | 원문 |
|---|---|
| E1 | 허용(타세력/설극루). 단 작용 결 다름: 洩 / 耗 / 剋. |
| E2 | 최상위: 극설소모측 = 식상+재성+관성 가능. 계산은 설기·소모·극제 분리. |
| E3 | 1차 시험용 약화 묶음 유효. 순환(식상생재 등) 시 단순 합산 불가; 내부 강도도 다름. |
| E4 | 탈기 그룹으로 묶음; 1차 개수 + 2차 자리. 기전은 A-6에서 분리. |

**항목 상태:** 4/4 **방향 묶음 허용**, 메커니즘/강도 분리는 공통.

## 8. 동일 가중치 / 단순 개수 합산 허용 여부

| Expert | 원문 |
|---|---|
| E1 | **단순 글자 수 배분보다** 삼합·방합·육합·충극에 의한 성질 변환이 **우선 변수**. 동일 가중치 여부 자체는 미기재. |
| E2 | **생조측 글자 수 − 극설측 글자 수 같은 단순 계산에 동의하지 않음.** 십신 이름·개수 직접 점수화 반대. 방향 분류 ≠ 영향량 계산. |
| E3 | 십신별 **서로 다른 개인 가중치** 제시(+0.5~−0.6 등). 순환 시 단순 합산 불가. 5축 점수 합산은 본인 척도로 사용. |
| E4 | 1차에 이분법 **개수·자리 비교** 실전 유효. 자리 질 없으면 오판 → 2차 자리 비교 필수. “모든 글자 동일 가중”은 미기재(위치·록왕 가중 명시). |

**항목 상태:** **Open disagreement** — E2는 단순 개수 합산 거부; E4는 1차 개수 비교 허용; E3는 차별 가중 점수제; E1은 개수보다 합충회국 우선.

## 9. 편/정이 1차 방향을 바꾸는지, 강도만 바꾸는지

| Expert | 원문 |
|---|---|
| E1 | 표에서 정·편 모두 같은 강/약 칸. 강도·결 차이는 서술(상관>식신 급격도, 편관 칠살 등). “방향은 같고 강도만” 문장 자체는 미기재. |
| E2 | **정·편 또는 음양 차이가 강약의 기본 방향을 뒤집지 않음.** 식신·상관도 1차 방향 동일(해석상 음양 차이는 별개). |
| E3 | 관: 1차 약화 동일, 격·위험은 별도. 식상·재·관 내부 **평균 가중 강도 서열** 제시(상관＞편관＞식신＞편재＞정재＞정관). |
| E4 | **편은 강도 극단**(편관>정관, 상관>식신, 겁재>비견). 방향 표는 정·편 동일 +/−. |

**항목 상태:** Partial — E2·E4 명시적으로 방향 유지·강도 차이. E1·E3는 표/가중으로 동일 방향+강도차 시사, E1은 명제 미기재.

## 10. 월령 중요도

| Expert | 원문 |
|---|---|
| E1 | 월지 = 사령, 전체 세력 약 **30~40%**, **절대 아님**. 실령+강득지·득세 → 신강 가능; 득령+극설 과다 → 득령무세 신약 가능. |
| E2 | 월령 **매우 중요하나 절대적 단독 판정값 아님**. 판단 순서 맨 앞. 단순 득령/실령 이분법 채택 안 함. |
| E3 | 5축 ① 득령(月支 12운성) 가중 **±1.0**(개인 제안). 旺·臨官·長生 +1 / 衰死絶墓 −1. |
| E4 | **월지 > 일지 ≥ 다른 지지 > 천간**. 득령이 사령 힘 결정 → **월지 1순위**. |

**항목 상태:** 4/4 월령 중요. “절대/단독” 거부는 E1·E2 명시. E3·E4는 수치·순위 개인안.

## 11. 통근 / 득지 중요도

| Expert | 원문 |
|---|---|
| E1 | 득지(일지 포함 지지 통근) = 실질 지구력·물리적 기반. 실령해도 유기 통근 시 자생력 강함. 신강 정의에 통근·주도권 포함. |
| E2 | 순서상 월령 다음 **일간 통근**. 통근 중요; 천간 비겁·인성 많아도 기반 약하면 숫자 그대로 불인정. |
| E3 | 축 ② 득지(日支 12운성) **±0.7**; 축 ③ 득세(통근·투간) **±1.0**(개인 제안). |
| E4 | 득지(일지)=직접 안착, **2순위**. 록·제왕지 가중↑. 통근형 비겁 강조. |

**항목 상태:** 4/4 통근·득지 중시.

## 12. 천간 투출 vs 지지 통근 상대 중요도

| Expert | 원문 |
|---|---|
| E1 | 무근 인성 < 실질 통근 비겁(체감). 학파란: 적천수는 지지 통근·합국 세력 전이 최우선. 천간 vs 지지 일반 순위 문장은 미기재. |
| E2 | 같은 정인이라도 월령·뿌리 있는 것 ≠ 지장간 미약. 천간 다수 ≠ 기반 약할 때 그대로 인정. |
| E3 | 득세: 본기투출 +0.5 / 중기 +0.3 / 여기 +0.1 / 통근無 −0.5 (개인 제안). |
| E4 | **지지(뿌리) > 천간(투출)** 원칙. 예외: 동일 오행 천간 **3개 이상**이면 지지 하나와 맞먹는 무게로 상향. |

**항목 상태:** Partial — 전원 “자리·뿌리 질” 중시. E4만 지지>천간+3자 예외를 명시. E3는 투출/지장간 차등 점수.

## 13. 합충 반영 방식

| Expert | 원문 |
|---|---|
| E1 | 단순 글자 수보다 **합·충·회·국이 세력 판정 우선 변수**. 합국 형성 시 강약 판도 급변. |
| E2 | 판단 순서에 **합충 등에 의한 변화** 포함. (케이스에서 子午沖 등 적용 사례 있음.) |
| E3 | 축 ⑤ 합충: 喜神합 +0.3 / 用神沖 −0.3 / 격파충 −0.5 / 자형·六害 −0.3 (개인 제안). |
| E4 | Phase A/B 방법론에 합충 반영 절차 **미기재**. (케이스 근거에도 합충 미언급.) |

**항목 상태:** Partial — E1·E2·E3 반영. E4 미기재. E3만 희신·용신 용어를 합충 축에 넣음.

## 15. 조후·격국·용신 등 Strength 외 요소 혼합 여부

| Expert | 원문 |
|---|---|
| E1 | 학파란에 **난강망 조후**·**적천수 통근·합국** 관점 기술. 케이스 조건부에 **종살격** 언급. 세력 점수축에 조후를 넣은다고는 미기재. 용신 확정 절차 미기재. |
| E2 | **격국·용신·희신·운 길흉은 판단하지 않음** 명시. 조후를 세력 축으로 쓴다는 기재 없음. |
| E3 | **혼합함.** 5축에 **조후** 포함; 합충에 **喜神·用神** 용어; Phase A에서 격·용·억부 용신 후보·종격/화격 조건부 기술. 다만 “강약 점수와 격은 합산치 아님”도 명시. |
| E4 | 세력 판단에서 **격국 배제** 명시; 종격은 조건부 참고만. 조후·용신을 세력 축으로 쓴다는 **미기재**. |

**항목 상태:** **Open disagreement** — E2·E4는 세력과 격/용 분리 지향. E3는 조후·용신 용어를 세력 점수에 편입. E1은 학파·종격 참고 수준.

## Agreement / Disagreement 요약
