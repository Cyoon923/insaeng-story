## 3. Phase A — 자유 서술 (A-1 ~ A-11)

※ 질문지 세부 문항을 별도로 받지 못했으므로, 주어진 주제축(식상·재·관의 영향 / 비겁·인성의 영향 / 같은 방향 묶음 가능 여부)을 A-1~A-11로 구성하여 답합니다.

**A-1. 식상의 세력 영향** — 직접 설기(洩). 일간이 기를 내주는 방향으로, 작용이 가장 즉각적입니다. 천간 투출·지지 통근 모두 실질화되며, 상관이 식신보다 설기량이 큽니다. 강도는 "일간 대비 식상의 왕쇠"에 좌우됩니다 — 식상이 득기하면 약화 폭이 커지고, 일간이 강하면 설기가 오히려 조화로 보일 수 있으나 세력 계산에서는 어느 쪽이든 감소로 산정합니다.

**A-2. 재성의 세력 영향** — 직접 극·설이 없는 "我克" 관계라 1차 감소 기제는 약합니다(耗). 핵심 기제는 **財破印**: 인성이 있을 때 재가 인의 조력을 깨뜨려 간접 감소가 실질화됩니다. 인성이 없으면 재는 사실상 중립에 가깝습니다. 정재·편재의 방향 차이는 없고 강도 차이만 미미합니다.

**A-3. 관성의 세력 영향** — 직접 극제(剋制)로 감소. 칠살이 정관보다 맹렬합니다(동성극). 단, 인성과 짝을 이루면(官印相生, 殺印相生) 극이 화(化)되어 완화되는데, 이는 "완전 상쇄"가 아니라 "일부 전환"으로 처리해야 합니다. 財滋殺 체인(재생살)은 감소를 증폭합니다.

**A-4. 비겁의 세력 영향** — 동기(同氣)로 최대·최확실한 조력. 지지 통근(득지)과 천간 투출(득세)이 모두 조력으로 산정되며, 지지 帝旺(陽刃)이면 극강 근이 됩니다. 겁재는 재성 견제(財극)를 겸하므로 재다 원국에서 실질 조력이 더 커지고, 비견은 순수 동기 보강입니다.

**A-5. 인성의 세력 영향** — 생(生我)으로 조력. 비겁과 다른 점은 **방어 기능**(관살의 극을 화하고, 편인의 경우 도식으로 식상 설기를 차단)입니다. 정인은 순생, 편인은 "생 + 식상극"의 이중 작용이라 식상 다수 원국에서 편인의 세력 보전 실효가 더 큽니다. 지지에서 인성의 장생·왕지(예: 亥中壬, 子中癸)면 조력이 강합니다.

**A-6. (식상·재·관) 같은 방향 묶음 가능 여부** — 거시적으로 가능합니다. 셋 다 세력 감소 방향. 단 기제가 泄(식상) / 克(관살) / 耗·破印(재성)의 3갈래로 나뉘므로, 총량 비교는 1차 필터로만 쓸 수 있습니다. 가중치는 대략 **칠살·상관 ≫ 식신·정관 > 재성(인 유무로 0~중간)**. 특히 재성은 "조건부 감소"로 분리 관리하는 것이 안정적입니다(근거: A-2).

**A-7. (비겁·인성) 같은 방향 묶음 가능 여부** — 가능합니다. 둘 다 조력이며, 세력 산정에서는 통근·투출에 같은 가중을 줘도 무방합니다. 다만 역할이 다릅니다 — 인성은 방어 겸비(관살화·도식차단), 비겁은 재극 겸비. 월지가 이 계열이면 득령으로 처리합니다(①과 직결).

**A-8. 묶음의 한계 (일반 원칙)** — ① 방향만 같고 강도·기제가 다르므로 묶음 총량은 스크리닝용 ② 투출·통근·월지 위치의 가중치가 방향 부호보다 판정을 더 크게 좌우함(예: 천간 인성 3이어도 무근·파극이면 실효 반감 — Pilot 04) ③ 합화가 방향 자체를 바꿀 수 있음(예: 辰酉合은 재(辰)를 금(살)으로 전환 — Pilot 05) ④ 최종 등급 결정은 반드시 개별 십신 재계산으로.

**A-9. 월지(월령)의 위치와 가중** — 득령은 단일 최대 가중치입니다. 월지가 조력 계열이면 ① 긍정, 감소 계열이면 ① 부정. 단, 월지 지장간의 본기·중기·여기 중 어느 것이 천간에 투출되었는지가 실효를 좌우합니다(통근+투출 = 해당 십신의 왕성). 일간이 12운성상 死·絶地에 있어도 월지의 생조가 있으면 구제 요인으로 봅니다.

**A-10. 합·충·형·해의 수정** — ① 합화·반합: 지지 성분이 전환되어 근의 흡수·증강 발생(辰酉合, 寅午·子辰·申辰 반합 등) — 이때 해당 오행 계열을 가중 ② 충(子午 등): 근이 동요되어 지지 조력의 안정성이 반감(일부 학파는 발동으로 봄 — 본 판정은 "근의 불안정"으로 처리) ③ 형·해·파: 보조 참작, 단독으로 판정을 뒤집지 않음.

**A-11. 세력 등급 판정 원칙과 경계** — 판정 순서는 ① 득령 → ② 득지 → ③ 득세 → ④ 감소 총량 → ⑤ 합충 조정 → ⑥ 등급. 중화 판정 시 반드시 "경향"을 병기합니다(예: 중화, 기울면 편약). 등급은 원국 내 상대 비교치이며, 이 판정이 길흉·적중을 보장하지 않습니다 — 격국·용신·희신과 분리된 채집 데이터로 취급해 주십시오.

## 4. Phase B — 구조화

### 묶음 질문 (서술 우선)

**B-1. 감소 3종(식상·재·관)을 한 묶음으로 취급해도 되는가** → 가능합니다. 다만 기제 3갈래(泄/克/耗·破印)의 강도 차가 크므로, 묶음 총량은 "1차 필터"로만 쓰고 최종 산정 시에는 財를 독립 계열로 분리합니다. 실제 반례 — Pilot 04는 감소 계열(재 2 득령 + 식신 + 살)이 강하지만 인성 3이 맞서며 중화로 판정되는 등, 총량 단독 비교로는 등급을 결정할 수 없습니다.

**B-2. 조력 2종(비겁·인성)을 한 묶음으로 취급해도 되는가** → 가능합니다. 세력 산정상 같은 부호·유사 가중을 줘도 무방하나, 인성의 방어 기능(관살화·도식차단)과 비겁의 재극 기능은 감소 계열과의 상쇄 계산 시 기제별로 분리하는 것을 권장합니다. Pilot 02는 "천간 전부 조력 + 양인 2"로 묶음 조력이 절대적인데, 그래도 실령 감점을 빼면 편강에 머문다는 점이 묶음 판정의 한계 예시입니다.

**B-3. 묶음 총량만으로 최종 등급을 매길 수 있는가** → 불가합니다. Pilot 01: 감소 총량(식상 3 투출 + 관국)은 압도적이지만 지지 인성 통근(丑辰) 덕에 "극약"이 아닌 "편약"으로 등급이 올라갑니다. Pilot 05: 조력 총량은 亥 1개뿐인데 인성 생부로 차약(극약 아님)에 머뭅니다. 등급 경계선은 항상 개별 재계산이 결정합니다.
