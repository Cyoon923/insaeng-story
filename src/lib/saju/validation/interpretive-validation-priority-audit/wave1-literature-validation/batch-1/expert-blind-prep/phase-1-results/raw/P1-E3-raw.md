# 일간 세력 판단 — 박○○ 님 명식 8건

## ▎내 판단 기준 (5축 합산, -3 ~ +5 척도)

오늘부터 외부 엔진·블로그 답변 없이, 제 자신의 명리 기준으로만 판단합니다.

**5축 = 득령(得令) · 득지(得地) · 득세(得勢) · 조후(調候) · 합충(合沖)**

| 축 | +값 기준 | -값 기준 | 가중치 |
|---|---|---|---|
| ① 득령(月支 12운성) | 旺·臨官·長生 +1 | 衰·死·絶·墓 -1 | ±1.0 |
| ② 득지(日支 12운성) | 旺·臨官·長生 +1 | 衰·死·絶·墓 -1 | ±0.7 |
| ③ 득세(통근·투간) | 본기투출 +0.5 / 지장간 중기 +0.3 / 여기 +0.1 / 통근 無 -0.5 | 인성 과다 시 별도 -0.4 | ±1.0 |
| ④ 조후 균형 | 한(寒)·열(熱)·조(燥)·습(濕) 시 약 +0~ -0.5 | 균형 시 0 | ±0.5 |
| ⑤ 합충 | 喜神합 +0.3 / 用神沖 -0.3 / 격파충 -0.5 | 자형(自刑)·六害 -0.3 | ±0.5 |

총점이 **+3.5 이상 → 신강 / +1.5~+3 → 중화 / +1.5 이하 → 신약** 으로 1차 컷오프합니다. 인성·식상 과다 같은 “묶음 한 방향 일변도” 가 발견되면 위 ③에 별도 감점(印重身弱·식상 과다洩 등)을 부여합니다.

## ▎Phase A 서술 — A-1 ~ A-11

**A-1. 식상(食傷)** — 일간이 生하는 오행. *설기(洩氣)* 방향으로 일간을 약화시킵니다. 일간은 식상을 내보낼 때마다 자기 기운을 비웁니다. 단, **“식상 得氣 가능성(A-8)”** 을 항상 점검합니다.

**A-2. 재성(財)** — 일간이 極하는 오행. *소모(耗)* 방향. 식상보다 약하지만, 재가 많으면 일간이 빼앗기는 그림이 반복됩니다. 재 다신약(財多身弱) 만성화 위험.

**A-3. 관살(官殺)** — 일간을 極하는 오행. *극제(克)* 방향. 정관은 사회적 제약·질서=격 안정, 편관(七殺)은 공격·제압=격 붕괴 risk. 1차 일간 약화는 동일하나, **격 형성 여부** 가 별도.

**A-4. 인성(印)** — 일간을 生하는 오행. *조력(扶)* 방향. 토생금·수생목 같이 일간 자금을 채워줍니다. 이게 표준 1차 묶음의 한 축.

**A-5. 비겁(比劫)** — 일간과 같은 오행. *동류(同類)*. 비견은 자아 강화, 겁재는 경쟁·빼앗김 양면. 일반 조력이나 **비겁 過多 → 劫財 / 比肩 누설** 위험.

**A-6. 같은 방향 묶음의 유효성** — “식상·재·관 = 약화 1묶음 / 인성·비겁 = 조력 1묶음” 은 **1차 시험용으로는 유효**합니다. 다만 *순환(食傷生財, 財生官, 官印相生)* 이 성립하면 약화 묶음 중 한 부분이 회복되므로 단순 합산에 머물면 안 됩니다. 또한 “식상·재·관” 내부도 강도가 다릅니다(상관 ＞ 편관 ＞ 식신 ＞ 편재 ＞ 정재 ＞ 정관 순으로 평균 가중).

**A-7. 印重身弱 / 母慈滅子** — 인성은 “조력” 이지만 **印이 너무 많으면 격파**. 인성이 일간을 감싸고 본기(根)·기운이 인성 안에 갇혀 밖으로 못 나가면 일간이 오히려 질식합니다. **印 3~4개 + 식상 0 = 의심**.

**A-8. 식상 得氣 가능성** — 식상이 1차 약화이긴 하나, 식상이 旺 + 인성·재성이 유통시키는 구조면 식상은 *체(體)*가 아니라 *용(用)*. 명리 동의어: **식상생재(食傷生財) / 식상제살(食神制殺)** — 이때 식상은 격의 *engine*. 일간 세력 약화 단일 판정으로 처리하면 격을 놓칩니다.

**A-9. 비겁의 양면성** — 비겁은 조력 외에 다음 효과를 동시에 가집니다: (a) 인성을 깨면(財破印) 인성 약화 → 일간 약화 prompt. (b) 재를 들어내면(劫財) 사회적 손실·격파. (c) 겁재가 겁재에 부딪히면 *比劫爭財*. 단순 “조력 + ” 가 아니라 **상황 의존 양면** 성격을 명기합니다.

**A-10. 관살 = 단순 약화? — 아닙니다.** 정관격·편관격(七殺格)·상관격·식신격·재성격·인성격 등 어떤 월령이든 *격 자체* 가 될 수 있습니다. 따라서 “관이 있다 = 일간 약” 이라는 1차 문장만으로 단정하지 않고, **그 관이 격의 기준인지(격취)/ 통근·투간으로 살아 있는지(생존)/ 용신으로 눌렸는지(抑·化)** 를 분리 묻습니다.

**A-11. 동일 방향 묶음의 위험 — 결론**
- 자평명리: 단순 묶음 1차 유효.
- 적천수(滴天髓): *氣勢論* — 식상·재·관이 한 줄기로 흐르면 약화가 아니라 순환. 묶음 = 단일 흐름 다시 평가.
- 궁통보감·자평진전: 配氣 · 用神 우선 — 1차 묶음은 문지기, 2차 격·용이 결정.
- 현대 신강신약론(조훈생·諸橋 등): 12운성·통근 가중 일변도 — 묶음 약화보다 점수 합산 강조.
- **결론**: 저는 1차 묶음은 인정하면서, ③ 득세에서 “印重身弱·식상 과다·劫財” 의 별도 감점을 두어 묶음의 균열을 감지합니다.

### B-1. 십신 10행 영향표

| # | 십신 | 일간 세력 기본 방향 | 가중치(평균) | 조건 / 예외 |
|---|---|---|---|---|
| 1 | 비견 | 強(+조력) | +0.5 | 비겁 4개↑ → 劫財 -0.4 / 比肩 反 財 -0.3 |
| 2 | 겁재 | 強(+조력·-奪財) | +0.3 | 재 옆 겁재 → 劫財 -0.5 / 競爭·격 무너짐 |
| 3 | 식신 | 弱(설기) | -0.4 | 식상생재 격이면 -0.1 / 식신제살 격이면 -0.1 |
| 4 | 상관 | 弱(설기) | -0.6 | 상관 見 官 → 격파급 -1.0 / 식상생재 격이면 격수로 -0.1 |

| 9 | 편인 | 強(조력) | +0.4 | 印重身弱 의심 -0.4 / 財破印 시 -0.2 |

신강 신약 1차 컷오프는 5축 가중 합 -3~+5 점수 척도에서 **+3.5↑ 신강** / **+1.5~+3 중화** / **+1.5↓ 신약**. 위 표는 “추가” 가중치 (3축 기준 ±1.0 안에 흡수).

### B-2. 묶음 질문 답변

- **묶음 Q1.** *식상·재·관이 단순히 일간 약화인가?* — 1차 그렇습니다. 단, (a) 식상생재 (b) 식상제살 (c) 財生官 → 官印相生 같은 순환이 성립하면 한 위계 약화가 상쇄됩니다. 1차 묶음 + 3축 득세·합충에서 순환 점검.
- **묶음 Q2.** *인성은 무조건 조력인가?* — 기본 조력. 단 **印重身弱 / 財破印 / 印綬 太多** 시 약화. 인성 3개 이상 + 식상 0 + 토다목과 같은 결합이면 의심.
- **묶음 Q3.** *식상·재·관은 정말 한 묶음인가?* — 효과 강도는 다릅니다. 상관이 가장 약화 가속, 편관 다음, 식신·정관 안정. 1차 묶음과 별도로 “순환 위치” 분리.
- **묶음 Q4.** *신강·신약 점수와 격(格) 의 관계* — 강·약은 “격 가능성” 의 1차 문지기. 격은 월령·용신·조후·합충으로 결정. 강·약 점수와 격은 **합산치 아님**. 점수 용도: “이 일간 세력에서 어떤 십신 line 이 살아남는가” 의 시도.
- **묶음 Q5.** *시간 미상 명식 (08) 의 처리* — 점수 단일값 금지. **시주 후보별 점수 범위** 로 출력. 본 답안 08항 참조.

### B-3. 학파·조건부 자유란

- **자평명리** — 득령 중심, 신약이 일반 default. 印·비겁 가중 +1.
- **滴天髓 (적천수)** — 氣勢論. 順格 / 逆格 / 從格(종격). 신약이어도 *종격* 성립 시 별도 명명. 묶음보다 흐름 우선.
- **神峰通考 (궁통보감)** — 用神 중심. 신강·신약 2차.
- **子平真詮 (자평진전)** — 配氣(균형). 신강·신약 점수 합산보다 “오행 균형” 우선.
- **억부론 (任鐵樵·조옹)** — 신강이면 *용신 = 식상·재·관* / 신약이면 *용신 = 인성·비겁*. 본 답안은 이 원칙 따라 1차 용신 후보를 잠정 분류 (격 형성 별도).
- **조후설 (조훈생)** — 寒·暖·燥·濕 처방 우선. 신강·신약과 별도 1차.

**조건부 적용** (제 답안 기준):
- **종격(從格)** — 일간 무력 + 식상·재·관 旺 + 통근 無 → 일간 무시하고 그 오행이 격이 됨.
- **화격/합국** — 천간·지지 六合·三合 성립 → 일간이 변화·소멸, 새 일간.
- **가격(假格)** — 시주 미상이면 시간 추정 기준 다변.
