## D. 개념 혼용 검사

엔진 STR-010/011은 `collectStrengthEvidence`에서 십신 라벨을 support / pressure **한 축**에 넣는 것이다. 점수·용신·희신이 아니다.

같은 십신 말이 나와도 체계가 같다 보지 않는다.

| 개념 | 이번 Batch에서 Strength 직접 근거가 되는가 |
|---|---|
| 日主 세력(旺衰強弱, 黨眾, 盜氣, 剋身, 生身) | 예. E-YH-02/03/04/06, E-ZP-01/02, E-DT-04의 부신/극신 힌트 |
| 十神 기능 분류(生我/我生/剋我/我剋/同類) | 부분. 방향 언어는 있으나 엔진 4+6 집합과 1:1이 아님 |
| 格局 / 用神 / 喜忌 | 아니오. E-ZP-03, E-DT-02/07, E-YH-07은 **혼용 위험**. 반증·대안 체계로만 기록 |
| 生剋泄耗 / 扶抑 | 기능 차이의 언어. 한 side로 합치는 근거가 아님. E-DT-06이 오히려 분리 요구 |

**혼용 발견: 있음.** Batch 1은 용신 순역·체용 원주·繼善 귀부를 Strength 양축 정의와 같은 층으로 붙인 부분이 있다. 이번 문서는 그 항목을 격국/용신 문맥으로 재분류한다. 재분류 후에도 엔진 규칙과 **충돌하는 체계**로 남을 수 있으므로 삭제하지 않는다.

## E. STR-010 재검토 (이전: PARTIALLY-SUPPORTED)

엔진: 비견·겁재·편인·정인 → support. 정/편·幫/助 구분 없음.

사용자 질의 중 「세력 감소 방향 동일 집합」은 STR-011 주제다. STR-010은 도움 방향이다.

### 쟁점 분리

| 쟁점 | 문헌이 말하는 것 | 엔진 |
|---|---|---|
| 比肩 / 劫財의 幫身 | 沈: 비겁은 당중·朋友之相扶. 淵海: 비겁은 형제·분재, 재격에서 忌. 양인과 겁재를 同類로 묶음 | 비견·겁재를 항상 support |
| 正印 / 偏印의 生身 | 生我=生氣는 반복. 정편은 음양 명명 | 둘 다 support |
| 偏印 특수 | 倒食·吞啗. 식신/재용을 해침. 尊長制身 | 편인도 support |
| 印과 比劫을 같은 Strength side로 묶음 | 沈: `比劫印綬通根扶助為黨眾`. 任: 衰則幫助이나 幫≠助 | 한 Set |
| 같은 side ≠ 동일 강도 | 任이 명시 분리. 沈도 통근 가중을 비겁 개수와 다름 | 동일 boolean side |

### supporting

- 인 = 生我 / 生氣 / 生身 (E-YH-02, E-SM-01, E-YH-06)
- 비겁·인 = 당중 조후 (E-ZP-01)
- 원주: 印以扶身 (E-DT-04)

### limiting

- 淵海 다섯 갈래의 다섯째는 劫財·陽刃이지, 비견+겁재+정인+편인 한 묶음이 아님
- 幫 vs 助 (E-DT-06)
- 재격에서 비겁은 忌, 印은 生身 (E-YH-06)
- 정편을 세력에서 무시하라는 원문은 없음

### conflicting

- 倒食을 生氣 갈래에 넣으면서 식신을 해친다 (E-YH-01 + E-YH-05)
- 용신 순역은 印과 劫을 반대편에 둠 (E-ZP-03, 격국 문맥)

**verdict:** PARTIALLY-SUPPORTED 유지.  
근거가 인·비겁의 *도움 가능 방향*까지는 모인다. 네 십신을 조건 없이 한 support 집합으로 두는 정의는 재확인되지 않았다. SUPPORTED로 올리지 않는다.

**이전 → 현재:** PARTIALLY-SUPPORTED → PARTIALLY-SUPPORTED (변경 없음)  
**evidence confidence:** MEDIUM

## F. STR-011 재검토 (이전: CONTESTED)

엔진: 식신·상관·편재·정재·편관·정관 → pressure. 泄/耗/剋 구분 없음.

### 쟁점 분리

| 쟁점 | 문헌 | 엔진 |
|---|---|---|
| 식상 泄/盜/竊 | 있음 (E-YH-01/03, 繼善 逼迫) | pressure에 포함 |
| 재 耗/盜 | 재성신약일 때 財之盜氣 (E-YH-04). 재=부 구결도 있음 | 항상 pressure |
| 관 剋 | 剋身·受制 (E-YH-04, E-SM-01, E-DT-04) | 항상 pressure |
| 식상+재+관을 동일 약화 축 | 한 문헌도 세 기능을 동일 Strength side로 정의하지 않음. 沈은 財官食神 vs 傷官七煞을 나눔 (E-ZP-02). 任은 泄≠傷 | 한 Set |
| 정관/편관, 정재/편재, 식신/상관을 Strength에서 무시 | 삼명 `官喜正不喜偏`. 식신과 상관을 竊氣 음양으로만 묶고 격에서는 다름 | 무시 |

### supporting

- 식상 = 竊氣/盜氣
- 관 = 剋身 (조건·격에 따라)
- 설기가 많으면 秉令해도 不强 (E-ZP-01)
- 任이 인용한 子平 구결: 왕하면 泄·傷 (COMMENTARY, 그리고 본인이 곧 분리)

### limiting

- 식신은 복록의 신으로도 서술 (E-YH-03)
- 재의 盜氣는 **재성신약** 조건 (E-YH-04)
