## Case 1 — `w1b3-rd-01` (甲 · 여기만 · 辰월)

### 1) 판정 요약 (원문 방향)

| | E1 | E2 | E4 |
|---|---|---|---|
| **Strength (참고)** | 신약 쪽 | 신약 쪽 (무근 극약은 아님) | 신약 (시주 유보) |
| **Root 유무·위치** | 월지 辰 · 乙 여기(겁재) | 월지 辰 · 乙 (내부 木; 戊가 중심) | 辰 · **乙 여기**만; 申·子 무근 |
| **Root 깊이·유효** | **얕음(약함)**; 묘고 여기 + 申子辰 수국으로 독자력 약화 | **중간 이하**; 잔존 봄 木氣이나 순수 木支 아님; 월지라 무시 불가 | 층위 최얕 + 衰; **“있다고 말하기 애매한”** 수준 |

### 2) root 판단 핵심 근거
- 3/3: 유일한 木根 = 辰中 乙(여기/잔존). 寅卯형 직접 木旺根 아님.
- E1: 합국(수)으로 근의 독자성 약화.
- E2: 존재는 인정·강근 거부; 子는 근 아님·인성.
- E4: 여기+이기+衰 → 사실상 최소 인정.

### 3) 조건부·경계
- 시주 미상 (3/3).
- 辰中乙 인정 강도 · 수국/인성 비중 (학파).

### 4) 공통 방향 (root-depth)
- **통근 있음(여기)·유효는 약/얕음.**

### 5) 실제 disagreement
- Strength 방향은 공유(약). Root **인정 강도 표현**만 차이 (얕음 / 중간이하 / 애매).

### 6) root-depth 직접 관련 차이
- “여기만 = 어느 정도까지 근으로 셀 것인가”의 **인정 문턱**.
- **OD-1 연결:** 고지(辰) 여기 — E1 방법론상 고지에서 여기 발현이 중기보다 뚜렷할 수 있다는 축과 **같은 지지 유형**; 다만 본 case는 중기 土根이 일간 木이 아니므로 중기>여기 **서열 비교 사례는 아님**. 여기-only의 얕음 평가는 3/3.

## Case 2 — `w1b3-rd-02` (乙 · 월지 본기 · 寅申충) ★충 손상

### 1) 판정 요약

| | E1 | E2 | E4 |
|---|---|---|---|
| **Strength (참고)** | 득령하나 충·금으로 **심한 위협** (최종 라벨 덜 단정) | **신강** 쪽 (중화신강~신강) | **신강** (중화신강~신강) |
| **Root 유무·위치** | 월지 寅 · 甲 **본기** | 월지 寅 · 甲 본기 (木根 명확) | 월지 寅 · **甲 정기**; 申·酉 무근(금 쪽) |
| **Root 깊이·유효** | 본래 **극히 깊고 강함**(득령·제왕) → 寅申충으로 **실질 대폭 감쇄** | 월령+본기 **강근**; 충으로 안정성 영향 있으나 **근=0 거부** | **정기+록지** 매우 깊음; 일지 피극은 월주가 상쇄 가능 |

### 2) root 판단 핵심 근거
- 3/3: 월지 寅 본기/정기 甲 = 구조적으로 **깊은 근** + 월령 결합.
- 분기점: **충이 그 유효 깊이를 얼마나 깎는가.**

### 3) 조건부·경계
- 寅申충 전파 vs 당령 유지 (학파).
- 시주 미상; 일지 酉 피극 가중.

### 4) 공통 방향 (root-depth)
- **월지 본기 강근의 존재·구조적 깊이**는 공유.
- 충은 **무시하지 않음**(3/3이 영향 인정).

### 5) 실제 disagreement
- **충에 의한 근 손상 정도 (핵심).**
  - E1: 실질 강도 **대폭 감쇄** → Strength도 위협 서사.
  - E2: 영향 있으나 제거 안 함 → Strength 신강 유지.
  - E4: 깊이 평가를 충으로 크게 내리지 않음 → Strength 신강.

### 6) root-depth 직접 관련 차이
- **구조적 깊이(본기+월령) vs 충 후 유효 깊이**를 같은 축으로 둘지.
- Strength 불일치는 이 root 유효감쇄 차이의 **하류**로 기록 (혼동 금지: Strength 자체가 root 정답 아님).

## Case 3 — `w1b3-rd-03` (戊 · 午 중기×2) ★강도 폭 · OD-1 연결

### 1) 판정 요약

| | E1 | E2 | E4 |
|---|---|---|---|
| **Strength (참고)** | 신강 | 신강 쪽 | **극신강(태강)** |
| **Root 유무·위치** | 일·시 午 · **己 중기** | 일·시 午 · 己 (火 중심·土 부차) | 일·시 午 · **己 중기** 이중 |
| **Root 깊이·유효** | **매우 깊고 강함** (제왕·화토동궁·록) | 직접 土根은 **중간 이하** + 午 인성으로 생조; 子午충으로 100% 거부 | 층위는 중기이나 **제왕** 보강 → **이중 강근·최상급** |

### 2) root 판단 핵심 근거
- 3/3: 통근 = 午中 己(중기). 午 본기 丁은 인성축으로도 서술(E1·E2).
- 분기: **중기 층위 라벨을 “중간 깊이”로 둘지**, **제왕·자리로 최상급 유효로 올릴지**.

### 3) 조건부·경계
- 子午충 손상 정도 (E1·E2 명시; E4는 결론 흔들림 없음).
- 중기 vs 정기 차등 크기 (E4: 본 case는 차등 키워도 결론 유지).

### 4) 공통 방향 (root-depth)
- **중기 통근 존재 + 유효는 약하지 않음(강 쪽).**

### 5) 실제 disagreement
- Strength **등급** (신강 vs 극신강).
- Root **깊이 표현**: E2 “중간 이하 직접근” vs E1/E4 “최상급·매우 깊음”.

### 6) root-depth 직접 관련 차이 · **OD-1 연결**
- **중기 ≠ 자동 “중간 유효”** 의 전형. E4·E1은 12운성/화토동궁으로 중기를 상향; E2는 층위상 중간이하를 유지하며 인성으로 보완.
- OD-1(중기>여기 일관 서열)과 직접 대립하진 않으나, **“층위 서열만으로 유효 깊이 고정”** 거부의 case-level 증거.

## Case 4 — `w1b3-rd-04` (己 · 丑·辰 본기 · 寅월) ★방향 disagreement

### 1) 판정 요약

| | E1 | E2 | E4 |
|---|---|---|---|
| **Strength (참고)** | **중화~신약** | **중화신약~중화** | **신강** (중화신강~신강) |
| **Root 유무·위치** | 일지 丑 본기 己 + 년지 辰 본기 戊 | 丑 己 본기 + 辰 戊 본기 (+寅中 戊 부차) | 丑 **己 정기** + 辰 **戊 정기** + 寅 戊 여기(얕음) |
| **Root 깊이·유효** | **깊고 안정** (자좌 본기·묘고) | 근 존재는 **강**이나 寅월이라 **계절 세력은 왕성하지 않음** | 丑 = 정기+비견+일지 **최강**; 辰 정기도 깊음 |

### 2) root 판단 핵심 근거
- 3/3: **복수 본기/정기 통근 분명** (특히 丑).
- 분기: 그 근의 **유효**를 월령 木旺·死/불리와 어떻게 합성하는가 → Strength 방향 분기.  
  ※ 합성 결과는 Strength; **root 존재·층위(본기) 자체는 대체로 합의**.

### 3) 조건부·경계
- 시주 미상.
- 목극토 vs 丙 통관 / 월령 死 전복 가능 여부.

### 4) 공통 방향 (root-depth)
- **본기(정기) 통근 있음·구조적으로 깊음/중요.**
- 월령은 土에 **불리**하다는 인식 공유(표현: 목왕절 / 계절 불리 / 死).

### 5) 실제 disagreement
- **Strength 방향: E1/E2 약~중화 vs E4 신강** (문서 요청 분리 기록).
- Root-depth만 보면 “근이 없다/얕다” 쪽 불일치는 **아님**.

### 6) root-depth 직접 관련 차이
- **본기 강근의 유효를 월령 불리가 얼마나 깎는가** (Case02 충과 대칭 구조: 구조 깊이 vs 환경 감쇄).
- E2가 명시: 근 존재 강 ≠ 계절 세력 왕성 — root-depth 축 분리의 핵심 사례.
- Strength disagreement는 이 감쇄·전복 가중 차이의 하류.

- 월지 vs 년지 가중 (위치 축) — 엔진 “전 지지 동일”과 긴장하는 **전문가 관찰**(채택·정답 아님).

### 4) 공통 방향 (root-depth)
- **월지 본기 단근 · 구조·유효 모두 강.**

### 5) 실제 disagreement
- Strength **폭**: E1만 중화까지 넓게; E2/E4 신강 쪽.
- Root-depth 방향 불일치 없음.

### 6) root-depth 직접 관련 차이
- “강근 1곳”을 얼마나 압도적으로 볼지 — **개수 vs 질**. Strength 중화 서사는 재성 대치 가중(하류)에 가깝고, root 층위 자체 쟁점은 약함.
