## 1. 4/4 공통 합의 (Phase A/B)

아래는 E1~E4 **전원**이 Phase A/B에서 같은 방향으로 말한 항목이다. “정답” 또는 STR 승격이 아니다.

| # | 합의 내용 |
|---|---|
| 1 | 월령·득시는 세력 판단의 **출발/최상급 축**이나, **단독으로 최종 신강·신약을 확정하지 않는다** |
| 2 | **득시 ≠ 자동 신강** (통근·득세·반대세력 등 추가 확인) |
| 3 | **休 ≠ 囚·死** 동일 약화로 묶지 않는다 (강도·회복 난이도 구분) |
| 4 | **실령**이라도 강한 통근·득세가 있으면 **최종 신강으로 뒤집을 수 있다** |
| 5 | **득령**이라도 강한 설기·소모·극제가 있으면 **최종 신약으로 뒤집을 수 있다** |
| 6 | **계절 상태(旺相休囚死·득/실령) ≠ 최종 Strength(신강/중화/신약)** — 반드시 분리 |
| 7 | **합·충**은 월령·통근의 실효에 영향을 줄 수 있다 |
| 8 | **기계적 점수만으로** 최종 신강/신약을 확정하는 것에 **반대하거나 강하게 경계**한다 |

**observation (채택 금지):** E1 월령 35~40%, E3 5축·왕상휴수사·십신 고정점 등은 개인 척도일 뿐이며 이번 집계에서 규칙으로 채택하지 않는다.

## 2. Open disagreement (3개)

다수결로 닫지 않는다. 방법론 충돌로만 기록한다.

### OD-1. 충돌 시 최종 우위

월령과 통근·득세·설모극이 충돌할 때 **무엇이 최종을 닫는가**.

| Expert | 원문 요지 |
|---|---|
| E1 | 최종 우위: **지지 통근의 유기성·합국 실질 균형** > 계절(월령) 기세 |
| E2 | **월령으로 기본 체력** → 통근 → 득세·설모극으로 유지/증감. **강한 월령을 가볍게 뒤집지 않음**(비대칭) |
| E3 | **1순위 월령 게이트**(득령 실패 시 신강 단정 금지) → 2 통근 → 3 투출. 종·역격 시 예외 |
| E4 | 월령=**출발 방향**; 최종=**생조 대 탈기 총합**(개수+자리의 질) |

→ **미해소.** 엔진/STR 승격 금지.

### OD-2. 식·재·관 감쇄 순위

반대 세력의 **상대 강도 순서**.

| Expert | 원문 요지 |
|---|---|
| E1 | **관살 > 식상 > 재성** |
| E2 | 식=설기·재=소모·관=극제 — **동일 −1 거부**, 순위표는 미제시 |
| E3 | 십신별 **개별 가중표**(상관/편관 −0.6 등) — observation only, 채택 금지 |
| E4 | 즉각 파급: **식상 > 관성 > 재성**; 다만 관성은 지속 억압으로 가장 위협적일 수 있음 |

→ **미해소** (특히 E1 vs E4의 즉각 순위 충돌).

### OD-3. 통근 vs 월령 “최대 비중”

둘 다 중요하다는 점에서는 가깝지만, **어느 쪽을 최대 비중으로 말하는가**가 갈린다.

| Expert | 원문 요지 |
|---|---|
| E1 | 월령=제1 기준(35~40%); **일지 통근은 월령 못지않은 결정적 실세** |
| E2 | 월령=최우선급; 통근=**월령 다음**으로 특히 중요 |
| E3 | 월령=1차 게이트·제1축; 통근=**2순위** |
| E4 | 월령=출발·1차 가늠자; 통근을 **실질적으로 가장 비중 있게** 봄 |

→ **미해소.** “둘 다 중요”는 공통에 가깝고, **최대 비중 표현**만 open.

## 3. E1~E4 특이 방법론

| Expert | 특이점 (Phase A/B) |
|---|---|
| **E1** | 충돌 시 **합국·통근 실질**을 월령 기세보다 최종 우위; 감쇄 **관>식>재**; **유통**(살인상생 등) 필수 고려 |
| **E2** | 전복 **비대칭**(강한 월령 경량 전복 거부); **Seasonal Strength / Final Day-Master Strength** 이중 변수; 충→근 **즉시 0** 계산 반대; 존재→세력→작용 순서 |
| **E3** | **5축**(득령·득지·득세·조후·합충) + 고정 점수 척도(입구로만); **12운성→旺相休囚死 압축**; 득령 실패 시 **신강 단정 금지** 게이트; 종·역격으로 월령 절대성 하향 |
| **E4** | 통근 **실질 최대 비중**; **절기 초/정기·월률분야**; 투출 **중첩** 시 지지급 상향; 점수=1차 스크리닝 후 질·합충·절기 정성 3단 |

수치·가중치는 위 표에서도 **observation**이며 채택하지 않는다.
