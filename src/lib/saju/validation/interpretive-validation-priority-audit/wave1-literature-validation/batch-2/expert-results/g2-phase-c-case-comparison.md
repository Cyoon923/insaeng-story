## Case 1 — 庚 (甲子 丙寅 庚午 壬午)

| | E1 | E2 | E4 |
|---|---|---|---|
| **최종 세력** | 극신약 | 신약 | 극신약 |
| **월령 상태** | 死 (절지) | 囚 | 死 |
| **통근 역할** | 金 통근 전무; 화국·칠살·편재로 극벌 | 뚜렷한 金根 없음; 재·관·식상만 작용 → 월령 약화 유지 | 비겁·인성 전무; 탈기군 전면 |
| **조건부·경계** | 종살격 검토 가능하나 억부상 극쇠; 壬·子는 증발 | 극신약 여부는 통근 인정 방식에 갈릴 수 있으나 신약 방향 분명 | 세력상 극신약 명확(종격은 범위 외 참고) |

- **공통 방향:** 3/3 **약(신약 계열)**
- **실제 disagreement:** (1) 월령 라벨 **死(E1·E4) vs 囚(E2)**; (2) 강도 **극신약 vs 신약**

## Case 3 — 丙 (癸亥 乙丑 丙寅 甲午)

| | E1 | E2 | E4 |
|---|---|---|---|
| **최종 세력** | 신강 | 신강 (중화신강~신강 중 택 신강) | 중화신강 ~ 신강 |
| **월령 상태** | 休 (실령) | 死 | 休 |
| **통근 역할** | 寅 장생·午 양인·甲乙 인성 → 실령 뒤집고 신강 | 午 강근 + 寅·甲乙 생조 → 死 불리함 상당 부분 뒤집음 | 일지 편인·시지 제왕 비견·인성 투출 → 休 뒤집음 |
| **조건부·경계** | 관인상생으로 약화 안 함 | 월령 중시 시 중화/중화신강 가능 — 死 vs 생조 비중 쟁점 | 休 감점 vs 제왕지 통근 — 중화신강↔신강 경계 |

- **공통 방향:** 3/3 **강(신강 계열)** — 실령/불리 월령 + 강통근으로 **최종 뒤집힘** 서사 공유
- **실제 disagreement:** (1) 월령 라벨 **休(E1·E4) vs 死(E2)**; (2) 강도 표현(단정 신강 vs 중화신강~신강)

## Case 4 — 壬 (己未 丙子 壬寅 丙午)

| | E1 | E2 | E4 |
|---|---|---|---|
| **최종 세력** | 신약 (중화신약) | 중화신약 | 신약 ~ 중화신약 |
| **월령 상태** | 旺 | 旺 | 旺 |
| **통근 역할** | 월지 子 양인뿐; 식재관 포위·寅午 화국 → 득령무세 | 子 강근이나 추가 생조 부족; 설기·재·관이 旺을 약화 | 월지 하나뿐 생조; 나머지 6자 탈기·재다신약 |
| **조건부·경계** | 극신약은 아님; 득령무세 신약 | **최대 경계** — 중화/중화신강↔신약 가능; 본인은 중화신약 | 旺·제왕 가중 시 중화신약 / 수적 열세 시 신약 |

- **공통 방향:** 3/3 **약 쪽(신약~중화신약)**; 월령 **旺** 일치; **득령 ≠ 최종 신강** 서사 공유
- **실제 disagreement:** 강도·경계선만 (중화신약 고정 vs 신약~중화신약 스펙트럼) — 방향(약)은 공유

## Case 6 — 癸 (己亥 丙子 癸卯 戊午)

| | E1 | E2 | E4 |
|---|---|---|---|
| **최종 세력** | 중화 ~ 약신강 | 신강 | 신약 ~ 중화신약 (경계선) |
| **월령 상태** | 旺 | 旺 | 旺 |
| **통근 역할** | 子·亥 비겁 기반 vs 卯·戊午·丙 견제 → 팽팽 | 亥子 복수 水根; 극설소모는 있으나 신약까지는 안 떨어짐 | 월·년 생조 질 좋음 vs 4자리 탈기·일지 무근 → 개수/질 충돌 |
| **조건부·경계** | 합·파로 견제 유효하나 건록·제왕으로 주도권 유지 | 중화신강까지 낮출 수 있으나 본인=신강 | 학파에 따라 중화신약↔신약 |

- **공통 방향:** **없음 (방향 open)** — E1 중화~약신강 / E2 신강 / E4 신약~중화신약
- **실제 disagreement:** **최종 세력 방향 불일치** (강 vs 중 vs 약). 월령 **旺**만 3인 일치
- **조건부·경계:** 3인 모두 “旺+통근 vs 설모극” 비중을 경계로 명시 — 대표 open case
