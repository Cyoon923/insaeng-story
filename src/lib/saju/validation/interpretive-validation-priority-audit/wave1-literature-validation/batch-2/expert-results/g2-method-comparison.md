## 1. 월령·득시의 중요도

| Expert | 원문 요지 |
|---|---|
| E1 | 가장 기본·출발점. 단독 결정 아님. |
| E2 | 최우선급·가장 큰 환경 변수. 최종 판정 그 자체는 아님. |
| E3 | 1차 게이트·우선순위 1위. 단독 결정 변수 아님. 종·역격 징후 시 절대성 1단계 하향. |
| E4 | 출발점·1차 가늠자. 절대적 결정자 아님. |

**상태:** **4/4 공통** — 월령은 최상급/출발 축이나 단독으로 최종 신강·신약을 닫지 않음.

**observation (수치):** E1 체감 35~40%; E3 월령 단독 ±1.0·“50% 이상”·“70~80%” 서술 — 개인 척도, 합의 아님.

## 2. 득시 = 자동 신강 여부

| Expert | 원문 요지 |
|---|---|
| E1 | 곧바로 신강 단정 불가. 득령무세 → 신약 가능. |
| E2 | 득시 ≠ 자동 신강. 통근·득세·반대세력·월령 유지 확인. |
| E3 | 아님. 본기·인성·순환 3단 확인 후 신강 단정. |
| E4 | 아님. 통근·투출·절기 초/정기 등 추가 확인. |

**상태:** **4/4 공통** — 득시만으로 최종 신강 확정하지 않음.

## 3. 旺·相·休·囚·死 사용 방식

| Expert | 원문 요지 |
|---|---|
| E1 | 계절적 생극 상태 = 일간 ‘기초 활력치’. 오행 정의(당령·생·설·극·반극). |
| E2 | 계절 상대 활동력 기준. **최종 신강·신약과 동일시하지 않음.** 旺=신강·死=신약 등식 부정. |
| E3 | **12운성을 다섯 단계로 압축**해 씀. 단계별 의미 + 고정 가중치 표. 점수 같아도 회복 형태 별도. |
| E4 | 월지 기준 오행 다섯 단계 = 월령으로부터 받는 **1차 힘의 방향**. |

**상태:** **부분 합의** — 4/4가 다섯 단계를 세력의 계절/1차 지표로 씀.  
**특이:** E3만 12운성 압축으로 명시. E1·E2·E4는 고전 왕상휴수사(오행·월령) 서술.  
**observation:** E3 旺+1.0 / 相+0.6 / 休−0.2 / 囚−0.7 / 死−1.0.

## 4. 休와 囚·死 구분

| Expert | 원문 요지 |
|---|---|
| E1 | 동일 취급 금지. 休=회복 용이; 囚·死=억압·극벌, 다수 인비 없으면 일으키기 어려움. |
| E2 | 동일 처리 금지. 旺>相>休>囚>死. 休를 실령=- 그룹으로 묶지 말 것. 등간격 수치화 경계. |
| E3 | 동일 약화 묶음 금지. 休/囚/死 회복 난이도 구분 + 세분 강도. |
| E4 | 동일 취급 안 함. 旺>相>休>囚>死. 休는 囚·死보다 훨씬 유리. |

**상태:** **4/4 공통** — 休 ≠ 囚·死 동일 약화.

## 5. 실령을 통근·득세가 뒤집을 수 있는지

| Expert | 원문 요지 |
|---|---|
| E1 | 가능. 실령(休·囚·死)라도 록왕지·인비 득세 → 신강. |
| E2 | 가능. 休·囚라도 강통근·비겁·인성 → 신강. (가볍게는 안 올림) |
| E3 | 가능. 월령 약+통근 강 → 신강. |
| E4 | 가능. 실령이라도 강통근·인비 득세 → 신강. |

**상태:** **4/4 공통** — 가능하다고 봄.

## 6. 득령을 설기·소모·극제가 뒤집을 수 있는지

| Expert | 원문 요지 |
|---|---|
| E1 | 가능. 득령이라도 월지 단독 통근+식재관 결집 → 신약(득령무세). |
| E2 | 가능. 다만 **강한 월령을 가볍게 뒤집지 않음**(비대칭). 旺→신약은 강한 반대 조건 필요. |
| E3 | 가능. 월령 강+통근 무+설기 강 → 신약. |
| E4 | 가능. 旺·相이라도 무근·식재관 강하면 신약. |

**상태:** **4/4 공통** — 뒤집힘 가능.  
**부분 합의 / 뉘앙스:** E2만 “비대칭·가볍게 뒤집지 않음”을 방법론으로 강조.

## 7. 계절 상태와 최종 Strength 분리

| Expert | 원문 요지 |
|---|---|
| E1 | 반드시 엄격히 구분. 월령 약→원국 신강 / 월령 강→원국 신약 사례. |
| E2 | 반드시 구분. Seasonal Strength vs Final Day-Master Strength **별도 보존** 선호. |
| E3 | 명확히 구분. 월령 단독(득/실/중화) vs 원국 전체(5축 합산) **별도 표기**. |
| E4 | 구분해야 함. 왕상휴수사=계절 국면; 신강·중화·신약=8자 총합. |

**상태:** **4/4 공통** — 계절 상태 ≠ 최종 신강/신약.

## 8. 통근의 중요도

| Expert | 원문 요지 |
|---|---|
| E1 | 실질 지구력. **일지 통근은 월령 못지않은 결정적 실세.** |
| E2 | 매우 높음. **월령 다음**으로 특히 중요. 근의 질·계절 세력 차별. |
| E3 | 월령 다음 **2순위**. 본기 유무. 본기無+월령失=쌍약. |
| E4 | **실질적으로 가장 비중 있게** 봄. 자리: 일지 > 연·시지 (월지는 별도). 록·제왕 가중. |

**상태:** **부분 합의** — 4/4 통근 매우 중요.  
**open disagreement (우선순위 표현):** E2·E3는 “월령 다음”; E4는 “실질 최대 비중”; E1은 일지≈월령급.

## 9. 천간 투출 처리

| Expert | 원문 요지 |
|---|---|
| E1 | 무근 투출=허세. 지지에 근 둔 투출만 실질 세력. |
| E2 | 중요하나 기반(근·계절·제약) 없는 개수 가산 거부. |
| E3 | 십신 투출 표 별도. 식·관·재 투출 개수가 신강→신약 전환 가능. |
| E4 | 지지 통근보다 가볍게. **중첩**(동오행 2+) 시 지지 하나급으로 상향. |

**상태:** **부분 합의** — 단순 투출 개수 ≠ 자동 세력 (E1·E2·E4 명시). E3는 투출 개수의 전환력을 더 크게 서술.

## 10. 비겁·인성 / 식상·재·관

| Expert | 원문 요지 |
|---|---|
| E1 | 비겁>인성(주체성). 감쇄: **관살 > 식상 > 재**. 유통(살인상생 등) 필수. |
| E2 | 생조측 방향 같으나 비겁≠인성 동일 항목. 식=설기·재=소모·관=극제. 동일 −1 거부. |
| E3 | 비겁/인성 기본 +가중 + 過多 감점. 식·재·관 **십신별 1·2차 가중표**. 순환 시 감점 완화. |
| E4 | 비겁=뿌리형·인성=생조형(+). 인성과다+무근=부유. 즉각 파급: **식상 > 관성 > 재**; 다만 관성은 지속 억압으로 가장 위협적일 수 있음. |

**상태:** **부분 합의** — 비겁·인성 = 생조(+), 식·재·관 = 약화 방향이나 메커니즘 구분.  
**open disagreement:** 감쇄 강도 순위 — E1 관>식>재 vs E4 식>관>재(즉각) / 관성 위협 병기.  
**observation:** E3 십신별 고정 점수표.

## 11. 합·충 처리

| Expert | 원문 요지 |
|---|---|
| E1 | 합=오행 본질 변화·판도 전복; 충=통근·생조 경로 파괴. |
| E2 | 변화 가능. 무조건 합화/완전 제거 거부. 충→근 즉시 0 계산 반대. |
| E3 | 합충이 월령·통근 힘을 옮김. 유형별 서술 + ±0.3~±0.5. |
| E4 | 변화 가능(원칙). 합화·충으로 월령·통근 실효 흔들림. 상세는 설문 범위상 생략. |

**상태:** **4/4 공통** — 합·충이 월령/통근 실효에 영향.  
**특이:** E2 “근=0 금지”; E3 수치 가중 observation.

## 12. 기계적 점수화 입장

| Expert | 원문 요지 |
|---|---|
| E1 | 고정 점수 합산의 치명적 위험=합충·유통 무시. 형충회합→유근→유통·조후 보완. |
| E2 | 최대 위험=旺相休囚死를 최종 Strength Score와 동일시. 월령·통근 중복 가산·균등 통근·전달력 무시. 중간층 분리 후 합성. |
| E3 | **5축 점수 척도를 쓰되 점수 단독 사용이 가장 위험.** 休=囚·死·본기0·순환 미반영·합충 과소/과대 위험. 점수=입구. |
| E4 | 월령 점수를 타 요소와 동일 가중 단순 합산이 최대 위험. 점수=1차 스크리닝 후 질·합충·절기 정성 검토. |

**상태:** **4/4 공통** — 숫자만으로 최종 신강/신약 확정에 반대(또는 위험시).  
**특이:** E3만 일상적으로 점수 척도를 방법의 일부로 유지(단독 단정은 거부).

## 충돌 시 우선순위 (항목 5·6·8 교차)

| Expert | 원문 요지 |
|---|---|
| E1 | 최종 우위: **지지 통근의 유기성·합국 실질 균형** > 계절(월령) 기세. |
| E2 | **월령으로 기본 체력** → 통근 → 득세·설모극으로 유지/증감. 강한 월령 경량 전복 거부. |
| E3 | **1 월령 게이트**(득령 실패 시 신강 단정 금지) → 2 통근 → 3 투출. 종격 흐름 시 예외. |
| E4 | 월령=출발 방향; **최종=생조 대 탈기 총합(개수+자리 질)**. |

**상태:** **open disagreement** — 충돌 시 “무엇이 최종을 닫는가”의 서술 순서·우위가 갈림 (E1 통근/합국 우위 vs E2·E3 월령 게이트/기본 체력 선행 vs E4 총합 확정).

## 집계 요약 (다수결 정답 아님)

### 4/4 공통
1. 월령은 출발/최상급 축이나 단독 최종 결정 아님  
2. 득시 ≠ 자동 신강  
3. 休 ≠ 囚·死 동일 약화  
4. 실령 + 강통근/득세 → 최종 신강 가능  
5. 득령 + 강설모극 → 최종 신약 가능  
6. 계절(왕상휴수사) ≠ 최종 신강/신약 (분리)  
7. 합·충이 월령·통근 실효에 영향  
8. 기계적 점수만으로 최종 확정에 반대/경계  

### 부분 합의
- 통근 매우 중요 (월령과의 **상대 순위** 표현은 갈림)  
- 투출은 기반·중첩 없이 단순 카운트하지 않음 (E3는 투출 전환력 강조)  
- 비겁·인성(+) / 식·재·관(−방향)이나 내부 강도·순위는 다름  
- 旺相休囚死를 1차 지표로 씀 (E3의 12운성 압축은 특이)

### open disagreement
1. **충돌 시 최종 우위:** E1(통근·합국) vs E2(월령 기본 체력·경량 전복 거부) vs E3(월령 게이트 선행) vs E4(생조/탈기 총합)  
2. **식·재·관 감쇄 강도 순위:** E1 관>식>재 vs E4 식>관>재(즉각)  
3. **통근 vs 월령 “가장 비중” 표현:** E4(통근 최대) vs E2·E3(월령 다음 통근) vs E1(일지≈월령)

### 전문가별 특이 방법
| Expert | 특이점 |
|---|---|
| E1 | 충돌 시 합국·통근 실질을 월령 기세보다 최종 우위; 감쇄 순위 관>식>재; 유통(살인상생) 강조 |
| E2 | 전복 **비대칭**; Seasonal vs Final **이중 변수** 명시; 충→근0 계산 반대; 존재→세력→작용 순서 |
| E3 | **5축·고정 점수표**; 12운성→왕상휴수사 압축; 득령 실패 시 신강 단정 금지 게이트; 종·역격으로 월령 하향 |
| E4 | 통근을 실질 최대 비중; 절기 초/정기·월률분야; 투출 **중첩** 상향; 점수=스크리닝+3단 정성 |

### observation only (수치·가중 — 합의·승격 없음)
- E1: 월령 35~40%  
- E3: 월령 ±1.0; 旺相休囚死 +1.0/+0.6/−0.2/−0.7/−1.0; 비겁·인성·식재관·합충 고정점; −3~+5 척도  
- E2·E4: 등간격/동일가중 점수화에 명시적 경계 (E4는 1차 스크리닝으로만 허용)
