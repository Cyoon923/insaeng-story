## 2. 전문가 observation → G6

### 2.1 한난 방향 (A-5 / CLI-018)

| Expert | 요지 |
|---|---|
| E1 | 寒←火 가온; 熱←水 냉각. 직접 온도 대립축 |
| E2 | 동일 방향; **단순 대칭 거부** (약한 지장간끼리 대칭 가정 거부) |
| E4 | 寒↔火, 熱↔水; 방향 예외 없음 |

**3/3:** 방향 관념 정렬 (문헌 PARTIAL과 맞닿음).  
**말할 수 없음:** clear mit → balanced 한 칸 · 일간 무시 overlay **VERIFIED**.

### 2.2 조습 + 土 (A-6 / CLI-019)

| Expert | 요지 |
|---|---|
| E1 | 燥←水·濕土; 濕←火·燥土. 조습은 水火+土 |
| E2 | 기본 濕←火 / 燥←水 + **辰丑濕土·未戌燥土** 필수 |
| E4 | 동일; 土 독자 조습 방향 — 火水만으로 부족 |

**3/3:** 조습에 土 개입; 火/水만의 역할표로 닫기 어려움 → CLI-019 CONTESTED와 맞닿음.  
**Open:** 土를 Climate factor로 쓸지 (vs CLI-013 POLICY).

### 2.3 한난·조습 동일 규칙? (A-7 / CLI-036·037)

| Expert | 요지 |
|---|---|
| E1 | **불가.** X온도 / Y습도 2축 |
| E2 | **완전 동일 규칙 불가.** temperature vs moisture regulation 분리 |
| E4 | **아니오.** 조습이 더 복잡(土) |

**3/3:** 동일 adjustPolar 함수로 한난·조습을 묶는 것에 **반대 방향**.  
문헌: CLI-036/037 CONTESTED (동일 함수 직접 근거 없음)와 정렬.  
**말할 수 없음:** 동일 함수 **VERIFIED** / 또는 CONTRADICTED로 문헌 재판정 (하지 않음).

### 2.4 조절 세기 (A-8)

| Expert | 요지 |
|---|---|
| E1 | 투출 / 통근 / 득령 / 성국 중 ≥1 |
| E2 | 투출·통근·월령·동류·합국·충 손상 등; existence ≪ effective strength |
| E4 | 투출·통근·득기; 여기만 = 존재 O / 조절 기여 낮음 |

**3/3:** 단순 존재 ≠ 조절.  
**Open:** quality clear 게이트·점수화 (CLI-021+ / W1B6-U2).

### 2.5 월령·일간 (A-9)

| Expert | 요지 |
|---|---|
| E1 | 월령·일간 **필수** |
| E2 | 월령 필수; 일간은 기후 판정 보조 |
| E4 | 둘 다 필요 (기후 vs 문제 소재) |

**3/3 월령.** 일간 깊이 = final-comparison OD-1.  
문헌: 窮通·沈은 일간×월령; 엔진 G6는 무관 — W1B6-U5.
